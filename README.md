# 2048 游戏

一个功能完善、动画流畅的经典2048游戏，支持桌面端和移动端。

![2048 Game](https://img.shields.io/badge/Game-2048-orange.svg)

## ✨ 特性

### 🎮 游戏功能
- **经典2048玩法** - 合并相同数字，目标达到2048
- **撤销功能** - 支持撤销最近5步操作，带步数提示
- **最高分记录** - 自动保存并显示历史最高分
- **游戏状态** - 游戏结束和胜利提示
- **继续游戏** - 达到2048后可选择继续挑战

### 🎨 视觉效果
- **流畅动画** - 丝滑的滑动和合并动画
- **响应式设计** - 完美适配各种屏幕尺寸
- **精美配色** - 渐变色方块，视觉舒适
- **硬件加速** - 使用GPU加速，性能优秀

### 📱 平台支持
- ✅ 桌面端 - 键盘方向键控制
- ✅ 移动端 - 触摸滑动控制
- ✅ 平板 - 完美适配

## 🏗️ 技术架构

### 核心技术栈
- **HTML5** - 语义化结构
- **CSS3** - 动画和样式
- **原生JavaScript** - 游戏逻辑

### 关键技术点

#### 1. 动画系统
- **绝对定位 + CSS Transition** - 精确的像素级动画
- **双重RAF** - 确保移动端动画正常触发
- **硬件加速** - 使用 `transform: translate3d(0, 0, 0)`

```javascript
// 关键动画代码
requestAnimationFrame(() => {
  requestAnimationFrame(() => {
    tile.classList.add("slide");
    tile.style.left = `${toLeft}px`;
    tile.style.top = `${toTop}px`;
  });
});
```

#### 2. 游戏逻辑
- **撤销系统** - 保存最近5步的棋盘状态和分数
- **合并算法** - 高效的方块合并和移动算法
- **碰撞检测** - 精确的移动和合并判断

#### 3. 响应式设计
- **vmin单位** - 适配所有屏幕尺寸
- **媒体查询** - 不同设备的优化适配
- **触摸优化** - 阻止默认滚动，优化手势识别

## 📊 动画性能

| 动画类型 | 时长 | 缓动函数 | 说明 |
|---------|------|---------|------|
| 滑动动画 | 200ms | cubic-bezier(0.25, 0.46, 0.45, 0.94) | 方块移动时的平滑过渡 |

## 🐛 已知问题修复

### ✅ 移动端动画不工作（已修复）
**问题原因：** 移动端浏览器对动画渲染有更激进的优化，单RAF会导致transition被跳过

**解决方案：** 
1. 先将元素添加到DOM
2. 使用双重requestAnimationFrame
3. 改用left/top transition替代transform

### ✅ 合并动画生硬（已修复）
**改进：**
- 缩放比例从1.25降至1.15，更自然
- 使用ease-out缓动函数
- 在滑动动画结束后才触发合并动画
